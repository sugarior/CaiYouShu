给 Agent 发一封控制邮件

从白名单邮箱发到你的 163 邮箱，主题以 [AGENT] 开头。正文使用下方格式，把口令、条件和收件人替换为实际值。

token: "config.yml 中的 control.token"
action: create
task:
  id: invoice_alert
  name: 发票提醒
  condition: 来信要求补充发票材料
  recipients: ["target@example.com"]
  instruction: 用中文概括所需材料和截止日期
